# 🏕️ SPA 快樂登山一頁式網站

一個結合形象宣傳、會員系統、地圖應用、進出貨功能的多元化單頁式露營網站。使用者除了可以瀏覽山區旅遊介紹，也能登入帳號後使用進階功能，如口罩地圖、旅館查詢與 YouBike 查詢等，打造資訊整合、互動友善的戶外活動平台。

---

## 🌟 專案功能特色

- ✅ 首頁形象式露營網站（介紹各大山區與登山團隊）
- ✅ 會員註冊、登入登出、會員後台管理
- ✅ 解鎖登入後功能：
  - 📍 全台旅館地圖查詢（Leaflet.js）
  - 🗺️ 口罩即時庫存地圖
  - 🚲 台中 YouBike 查詢與地圖視覺化
- ✅ 進貨建檔與進貨資料 CRUD 功能（產品、價格、數量、圖片上傳等）

---

## 🛠️ 使用技術說明

| 類別       | 技術內容 |
|------------|----------|
| 前端框架   | HTML5, CSS3, Bootstrap 5, jQuery |
| 地圖應用   | Leaflet.js, MarkerCluster, OpenStreetMap |
| 資料介接   | AJAX / JSON / 公開資料 API (如 Taichung YouBike) |
| UI 動畫   | Animate.css |
| 圖片上傳   | HTML5 File Input + 前端預覽 |
| 權限管理   | 自製會員登入驗證、控制台顯示、權限判斷 |

---

## 🧪 登入解鎖功能

登入後下拉選單將自動顯示以下功能：

- 🔓 控制台（會員名單管理）
- 🗺️ 口罩地圖（結合實際庫存查詢）
- 🏨 全台旅館查詢（使用 Leaflet 與 Marker Cluster）
- 🚴 YouBike 即時查詢地圖（含區域選單與更新時間）
